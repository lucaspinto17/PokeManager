
# PokeManager 🎮

Sistema de gerenciamento de Pokemon com Java e SQLite.
Como uma nova Pokedex, com voce podendo colocar o seu time favorito e muito mais!

## ✨ Funcionalidades:
-  Buscar Pokemon da API
-  Salvar no banco SQLite
-  CRUD completo
-  Times favoritos (até 6 Pokemon, padrão)
-  Interface console amigável

## 🚀 Como Executar:

### Pré-requisitos:
- Java JDK 21+
- VS Code com extensão Java

### Passos:
1. **Baixe o projeto** e extraia na pasta `PokeManager`
2. **Abra no VS Code** a pasta `PokeManager`
3. **Execute no terminal (Linux/macOS):**
	```bash
	./mvnw exec:java
	```

Não precisa instalar nada!

Tabelas criadas automaticamente
